# CALLIOPOL 2.2

Suite portable de aplicaciones para trabajar localmente con documentos, expedientes y herramientas de análisis.

## Descargar

**[DESCARGAR CALLIOPOL 2.2](https://github.com/Luismi2805/CALLIOPOL-descargas/releases/download/v2.2/CALLIOPOL-2.2-portable.zip)**

También puedes abrir la sección **Releases**, entrar en la versión más reciente y pulsar **CALLIOPOL-2.2-portable.zip** dentro de **Assets**.

1. Descarga el archivo ZIP.
2. Descomprímelo.
3. Abre la carpeta descomprimida.
4. Ejecuta **CALLIOPOL.bat**.

No es necesario instalar Python ni Git.

## Contenido

La portable incluye CALLIOPOL, RECONOPOL, DILIPOL, EXTRAPOL, OCRPOL, FOLIAPOL, ANONIPOL y NEXOPOL, además de la carpeta **INSTRUCCIONES**.

El procesamiento se realiza localmente. Los archivos originales no se modifican durante las operaciones previstas por cada aplicación.

NEXOPOL está en desarrollo y no todas sus funciones están implementadas o completamente terminadas.

Usa siempre datos ficticios para las pruebas y revisa los resultados antes de incorporarlos a un expediente.
